# Security policy

prompt-to-page runs locally. It has no backend and no accounts, and it doesn't collect or store user data. The only network calls go to the model provider you configure.

## Reporting a vulnerability

Report vulnerabilities privately through this repository's **Security** tab, using **Report a vulnerability**. For low-risk issues, you can open a regular GitHub issue. Never post API keys or other secrets in an issue.

## Keeping your keys safe

Keep your MiMo or other API keys in OpenDesign's settings or your local environment, and never commit them to this repository.
