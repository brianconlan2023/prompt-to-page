# Contributing

Thanks for helping make prompt-to-page better.

- **Keep it local-first.** Don't add cloud services, accounts or tracking.
- **Keep it small.** Make one focused change per pull request, and keep dependencies light.
- **Never commit keys.** API keys belong in your own environment, never in the repo.
- **Show the result.** For prompt or design changes, include the prompt and a screenshot of the page it produced.

## How to contribute

1. Fork the repo and create a branch.
2. Make your change and test it locally with OpenDesign.
3. Open a pull request that explains what changed and why.

For bugs and ideas, open an issue.
